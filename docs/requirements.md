# Соответствие требованиям КР 1

| Требование | Реализация |
|---|---|
| Java, интерактивная консоль | Main, Menu; повторяющиеся подменю, возврат после действия |
| PostgreSQL и JDBC | DatabaseConnection, JdbcRepository |
| Минимум две связанные сущности | Client, Equipment, RentalRequest; два внешних ключа |
| CRUD основной сущности | RentalRequestService и подменю заявок |
| Минимум один enum | RentalStatus, 5 значений, разрешённые переходы |
| Минимум 5 бизнес-правил | Перечислены в README; проверяются в service, а также ограничениями БД |
| Неверное число, ID, бизнес-ошибка, соединение, SQL | Menu, три собственных исключения, RegressionChecks |
| Два способа поиска | Заявки отдельно по имени клиента и названию оборудования |
| Два фильтра | Статус и диапазон даты начала; дополнительно фильтры оборудования |
| Две сортировки | Дата начала и стоимость; ASC/DESC через Comparator и Stream API |
| Минимум 5 показателей | Отдельный пункт «Статистика», 9 показателей |
| Основной экспорт Excel .xlsx | DataExporter, три выгрузки из данных PostgreSQL |
| Дополнительный CSV | UTF-8 с BOM, экранирование разделителей, кавычек и переносов |
| Инкапсуляция, конструкторы, методы | Модели Client, Equipment, RentalRequest |
| Интерфейс и полиморфизм | Repository<T,ID>; ClientService хранит интерфейс; реализации JDBC |
| Коллекции | List, ArrayList, Stream API, Comparator |
| Многослойная архитектура | UI → Service → Repository/JDBC → PostgreSQL |
| PreparedStatement, ResultSet, try-with-resources | JdbcRepository; значения передаются параметрами |
| PRIMARY KEY, FOREIGN KEY, NOT NULL, UNIQUE, CHECK | database.sql |
| 5 пользователей, 10 основных записей, 3 статуса | SQL создаёт 5 клиентов, 8 предметов, 10 заявок, 5 статусов |
| pom.xml, SQL, ER, Excel, инструкция | pom.xml, database.sql, docs/er-diagram.svg, exports, README |

Организационные требования (выбор свободного варианта, 4 участника, ФИО, номер группы и распределение выступления) выполняет команда. Данные об участниках не выдумывались.
